# Privacy policy (rclone-vps)

rclone-vps is a single-user application. Only its owner signs in to it.

- Data accessed: files and folders in the owner's own Google Drive, only to store and check the owner's backups.
- Use: the data is used only for these backups. It is not sold, shared, or transferred to anyone.
- Storage: the sign-in token is kept only on the owner's own server.
- Removal: the owner can revoke access at any time at https://myaccount.google.com/permissions
- Contact: through the GitHub account that hosts this page.
